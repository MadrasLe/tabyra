A auxiliar conecta uma janela dedicada do Chrome ao painel Tabyra. A comunicação com o backend usa uma conexão local autenticada. O pareamento é salvo neste perfil do Chrome.

Texto de páginas, capturas e resultados de ferramentas podem chegar ao provedor da sua IA pelo cliente MCP. O Tabyra não fornece um modelo nem promete que a IA processe esses dados localmente.

Esta versão não inclui serviço de coleta, publicidade ou envio de telemetria para o desenvolvedor. Chrome, o cliente de IA e os sites têm políticas próprias. A auxiliar não exporta o banco de senhas do Chrome nem copia o perfil para o navegador integrado.

O acesso de depuração permite controlar páginas. O programa limita as ações à janela dedicada. Use Fazer login no Chrome para liberar o controle temporariamente e Desconectar para remover o pareamento salvo, mantendo as abas abertas.
