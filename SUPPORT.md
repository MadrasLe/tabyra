# Support

Tabyra is a beta maintained by Gabriel Yogi. Contact **abrakasfrosken@gmail.com**.

Please include the Tabyra Browser/App/Connect versions, editor version, operating system, embedded/connected mode, exact error and a short reproduction. Redact account details from screenshots.

Never send `session.json`, `chrome-connection.json`, Chrome profiles, cookies, passwords, access tokens, `.env` files or complete host configuration. Prefer a minimal public test page over a reproduction that needs your account.

Windows is the validated beta platform. macOS/Linux are experimental. A working MCP client and its AI subscription are separate requirements. Login acceptance, CAPTCHA frequency and website availability are outside Tabyra's control.

For connection issues, open the panel and check its Chrome/AI state first. If a script times out, inspect the result before repeating an action. Do not repeatedly restart processes or submit the same form to diagnose an uncertain outcome. Security issues should be reported privately as described in [SECURITY.md](SECURITY.md).
