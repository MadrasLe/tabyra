## Browser / editor listing

Title: **Tabyra Browser**

Short description: **A browser shared by you and your AI, inside your editor.**

Tabyra gives you and an MCP-capable agent access to the same browser tabs beside your code. Watch the agent navigate, inspect a page, fill a form and insert code, or take over with your own keyboard and mouse. Pause the agent from the panel, or interrupt an active JavaScript operation without closing the tab.

Use an isolated embedded profile or connect a dedicated window of your regular Chrome profile through Tabyra Connect. The connected mode keeps your account sessions in Chrome and provides a manual-login handoff. A local pairing page saves the connection without repeated JSON copying.

The beta targets Windows desktop VS Code and Antigravity IDE. macOS/Linux are experimental; vscode.dev is unsupported. Tabyra supplies browser tools, not an AI model or subscription. Chrome/Edge is required. Website login acceptance and CAPTCHA behavior are not guaranteed.

Formerly Elektron Browser. The original IDs remain for compatibility with installed profiles and MCP settings. See the privacy and migration guides before connecting signed-in services.

## Chrome helper listing

Title: **Tabyra Connect**

Short description: **Connect a dedicated Chrome window to Tabyra's shared AI browser panel.**

Tabyra Connect is the Chrome companion for Tabyra Browser and Tabyra for Antigravity App. Pair it from the Tabyra panel, share one dedicated Chrome window, and keep control of your tabs. The connection is saved locally for reconnecting to the backend. The panel supports releasing debugger control for manual login and resuming afterward.

This helper requires a separate Tabyra installation. It does not provide an AI model. Browser text, images and tool results can be processed by the AI provider configured in your MCP client. It has no developer-operated telemetry endpoint; visited sites, Chrome and the AI client retain their own network behavior and policies.
